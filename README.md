## 📊 MySQL Data Analytics Project

## 📌 Overview

This project focuses on analyzing a business dataset using **MySQL** to answer important business questions and generate meaningful insights.

The dataset was loaded into a MySQL database, explored using SQL queries, and analyzed using different SQL techniques such as **Joins, CTEs, Subqueries, Aggregations, and Window Functions**.

The goal of this project is to demonstrate practical **SQL and data analytics skills** by transforming raw data into actionable business insights.

---

## 📂 Dataset

The dataset contains business-related information used to analyze:

- Customer behavior
- Sales and revenue
- Customer purchasing patterns
- Business performance

The dataset was imported into **MySQL** and structured into relational tables for analysis.

## 🔄 Project Steps

### 1. Data Loading
- Imported the dataset into MySQL.
- Created the required database and tables.
- Verified table structure and data types.

### 2. Data Exploration
- Examined the available tables and columns.
- Checked the number of records.
- Explored customer, product, and transaction data.

### 3. SQL Analysis
Used SQL queries to answer important business questions using:

- `SELECT`, `WHERE`, and `ORDER BY`
- `GROUP BY` and aggregate functions
- `JOIN` operations
- CTEs
- Window Functions
- Conditional logic

### 4. Business Questions

The analysis focused on questions such as:

- Who are the top customers by spending?
- Which countriess generate the highest revenue?
- What are the most popular products?
- What are the key sales and revenue trends?
- Which is the most popular music Genre for each country?

## 📊 Results & Insights

The SQL analysis helped identify important patterns in customer behavior and business performance.

Key insights included:

- Identified **top-performing customers** based on total spending.
- Determined **best-selling products and categories**.
- Analyzed **revenue contribution** across different segments.
- Used ranking and aggregation techniques to identify high-value business segments.
- Converted raw transactional data into **actionable business insights**.
